# lotse

lotse watches your websites, ports, certificates and cron jobs, and tells you
when something is wrong. One small program you run yourself, one page that
says whether all is well.

It is for a homelab, a blog and the parents' router as much as for the
websites of a few dozen customers: group checks into spaces when you want
to, and let others look at the spaces that are theirs.

lotse is starting over and has no release yet. How it is meant to work is in
[docs/design.md](docs/design.md), the settled points in
[docs/decisions/](docs/decisions/). lotse 0.1 is kept for reference at
[cowlhq/lotse-v0](https://github.com/cowlhq/lotse-v0).
