# 0006: Plain HTTP behind a reverse proxy, ACME optional

Date: 2026-10-25

Taken from lotse 0.1, decision 0006.

## Decision

- By default the hub speaks plain HTTP and sits behind the reverse proxy
  that already runs on the machine (Traefik, Caddy).
- For a machine without a proxy, the hub can get its own certificate from
  Let's Encrypt (`LOTSE_ACME_DOMAIN`).
