lotse.sh/cmd/lotse

The lotse binary: hub, agent, probe and command line in one.

go install lotse.sh/cmd/lotse@latest

Built this way, lotse has no web interface. To run the hub, use a release or the image ghcr.io/cowlhq/lotse; see Installing lotse.
